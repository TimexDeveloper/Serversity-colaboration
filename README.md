Проект интерактивной веб-платформы с глубокой интеграцией аудио и множеством уникальных страниц.

---

## 🛠 Технологический стек
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Библиотеки:** [jQuery 3.7.1](https://jquery.com/), [Howler.js](https://howlerjs.com/) (для работы со звуком)
* **CI/CD:** GitHub Actions (авто-деплой на GitHub Pages)
* **Уведомления:** Discord Webhooks

---

## 📂 Структура проекта
Проект организован по модульному принципу:
* `index.html` — Главная страница входа.
* `/Pages` — Дополнительные страницы (Lost, S1F0X, null и др.).
* `/MainMusic` — Аудио-библиотека проекта (m4a, mp3).
* `/BG` — Фоновые изображения и графические ассеты.
* `main.js` — Основная логика приложения.
